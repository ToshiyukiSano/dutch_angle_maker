# ダッチアングル変換

普通の動画を、傾けた「ダッチアングル」の映像に変換するブラウザアプリです。
手持ちカメラ風の手ブレも加えられます。

## 機能

- 傾き:-45°〜+45°
- 動き:固定 / じわじわ傾く / ゆらゆら
- 手ブレ:強さ 0〜100、速さ 3段階(ゆったり / ふつう / 激しい)
- 四隅:拡大して埋める(ズームは動画全体で一定)/ 全体を見せる
- 書き出し:MP4 または WebM(ブラウザによって変わります)

## 使い方

1. `index.html` をブラウザで開く(GitHub Pages でも動きます)
2. 動画を選ぶ
3. 角度や手ブレを調整して「傾けた動画を書き出す」
4. 書き出し後に「保存する」

## 仕組み

- 動画は端末内でのみ処理され、外部に送信されません。
- Canvas に回転・移動を加えて描画し、`MediaRecorder` で録画しています。
- 実時間で再生しながら録画するため、書き出しには動画の長さと同じ時間がかかります。

## 動作環境

最新の Chrome / Edge / Safari / Firefox。
Safari では MP4、その他では WebM で保存されることがあります。
